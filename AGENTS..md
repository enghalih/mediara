# AGENTS.md — Mediara Official Website

> Important Note: This document serves as the primary system context, architecture reference, and operating instructions for AI coding agents working on the Mediara website codebase. Based on the Plexify Creative Agency Tailwind CSS Template (DexignZone v2.0) and customized strictly for Mediara's single-page static architecture.

## 1. Project Overview

* **Name** : Mediara Official Website
* **Description** : A high-conversion, modern single-page static website for Mediara—a technology agency specializing in custom web applications (POS/Cashier, Livestock Management Systems), event & e-ticketing platforms, and high-impact landing pages.
* **Goal** : Establish credibility, present real project case studies, and drive direct lead acquisition via WhatsApp consultations without relying on external ticketing platforms or complex backends.
* **Target Users** : MSMEs / Retail / F&B, Agriculture & Livestock entrepreneurs, Service Businesses / Local Startups, and Event Organizers (Campus, Conferences, Weddings).
* **Architecture** : Pure Static Single-Page Website (100% Frontend only, NO Backend, NO Database, NO PHP/SMTP scripts).
* **Version** : v1.0.0 (Template base: Plexify v2.0)
* **Status** : Active development

## 2. Tech Stack

* **Platform** : Static Web Application (Single-page client-side HTML: `src/index.html`)
* **Markup** : Semantic HTML5
* **Styling** : Tailwind CSS v4 (`@tailwindcss/cli` v4.0.14)
* **Font Family** : Kanit (`--font-base: "Kanit", "sans-serif"`)
* **CSS Input File** : `src/assets/css/tailwind.css` (Theme tokens, custom color definitions, `@theme`)
* **CSS Output File** : `src/assets/css/style.css` (Compiled stylesheet linked in `src/index.html`)
* **Animation & UI Libraries (Plexify Vendor Assets)**:
  * GSAP (`src/assets/vendor/` or CDN)
  * Swiper JS (`src/assets/vendor/swiper/`)
  * WOW.js & Animate.css (`src/assets/vendor/wow/`, animate styles)
  * Template Core Script: `src/assets/js/custom.js` (Custom cursor, animations, smooth interaction)
* **Contact & Leads** : Direct WhatsApp Click-to-Chat API (`https://wa.me/`) — *PHP mailer/SMTP & Google reCAPTCHA from Plexify docs are strictly BYPASSED*.
* **Package Manager** : npm
* **Hosting / Deployment** : Vercel / GitHub Pages / Static CDN

## 4. Project Structure

Architecture: **Single-Page Application (One single customer-facing HTML file: `src/index.html`)**.

All original template pages are moved into `src/source/` strictly as component reference code.

```
web-design-agency/
├── logo.png               # Official Mediara brand logo
├── package.json           # Node scripts and @tailwindcss/cli dependencies
├── package-lock.json      # Locked dependencies

├── AGENTS.md              # System instructions and AI coding guidelines
└── src/
    ├── index.html         # THE ONLY ACTIVE PAGE (All 7 sections consolidated here)

    │   └── project-management.html # Reference for Vertical Timeline Workflow
    └── assets/
        ├── css/

        ├── icons/            # Template UI icons and SVG sprites
        ├── images/           # Mockups, screenshots, photos (.webp preferred)

        ├── vendor/           # Third-party plugins (GSAP, Swiper, Wow.js, etc.)
```

### File Placement & Migration Rules:

1. **Move original template HTML files to `src/source/`**:
   * `src/services.html` $\rightarrow$ `src/source/services.html`
   * `src/project-management.html` $\rightarrow$ `src/source/project-management.html`
   * Original template `src/index.html` $\rightarrow$ `src/source/index.html`
2. **Create fresh `src/index.html`**:
   * Consolidate all 7 sections into this single file.
   * Reference compiled stylesheet: `<link rel="stylesheet" href="./assets/css/style.css">`.
   * Reference necessary Plexify vendor scripts (`assets/vendor/...`) and `assets/js/custom.js` before `</body>`.
   * Never create separate user-facing HTML pages for services or pricing. Everything lives in `src/index.html`.

## 12. Do Not

* **DO NOT keep multiple public pages**—the final website must be a single `src/index.html`.
* **DO NOT install or configure backend runtimes** (no Express, no PHP, no SQLite, no Prisma).
* **DO NOT use PHP mail scripts or Google reCAPTCHA backend verification** from template docs—all contact goes through WhatsApp direct links.
* **DO NOT delete original template files**—move them safely to `src/source/` for reference.
* **DO NOT break vendor script paths**—maintain links to `src/assets/vendor/` and `src/assets/js/custom.js`.
* **DO NOT modify `src/assets/css/style.css` directly**—always edit `src/assets/css/tailwind.css` and compile via `npm run dev`.
* **DO NOT leave changes uncommitted**—always commit changes immediately via git.
